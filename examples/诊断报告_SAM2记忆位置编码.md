# SAM2 记忆位置编码改造 · 选题诊断

> **结论：条件可行，当前形态不可行。** 观察是真的（CT 的空间相邻被当成时间相邻），但作为独立创新的强度不够：相邻格子已被占满，预期增益小于噪声，且"连续编码"在源码里已存在。

## 三个致命点

**一、新颖性窗口很窄。** [SLM-SAM 2](https://arxiv.org/abs/2505.01854)（TMI'26，短期/长期双记忆库）、Spatial-SAM（CVPR'26，SDF 记忆替换）、[MedSAM-2](https://arxiv.org/abs/2408.00874)（按内容选帧、无视时序）已占据记忆改造的主要方向。可辩护的边界只剩"**记忆侧**的物理间距语义"，不能写成"改造 SAM2 记忆"。

**二、效应量测不出来。** 预期增益 1–3 Dice，而该任务标准差 ±0.13。差一个数量级 —— 问题不在方法，在指标。

**三、创新点已被源码消解。** `get_1d_sine_pe` 早已用于 object pointer 通路的带符号真实帧距，空间记忆通路却用离散查表。所以"改用连续正弦编码"是**补一致性**，不是新机制。反过来这也给了更强的立论：同一模型内两条记忆通路编码不一致，而这种不一致正是体数据迁移失效的结构性原因。

## 一条额外发现（建议单独立项）

`max_cond_frames_in_attn` 的文档写的是"只关注**时间上最近**的 N 个提示帧"。而 2603.23116 的 SPS（按距离筛提示帧，+1.9 Dice）通篇未提该参数存在。**SPS 可能只是把"最近 N 个"换成"距离 <0.3"。**

这是零代码、一周内可完成的实验。若成立，"已有参数即等效"本身就是可发表结论；若不成立，SPS 的归因才站得住。

## 可行路径：换指标，不换方法

主指标从**平均 Dice** 改为**提示效率曲线**（横轴提示数 1/2/3/5/9，纵轴 Dice，报 AUC 与达到目标精度所需最小提示数）。机制作用于"少量信息覆盖全体"，在均值上被稀释，在曲线上可表现为**达到同精度少用 40% 提示**。

立论同步升格：从"我改进了编码"改为"**视频基础模型的帧序号先验在各向异性空间采样下退化，其冗余结构解释了为何视频记忆超参不可迁移**"。这一版不需要新方法就有结论，且不与任何竞品冲突。

## 分档

| 档 | 目标 | 概率 | 周期 | 前提 |
|---|---|---|---|---|
| 高 | MICCAI / TMI | 25–35% | 4–6 月 | 换指标 + 零代码对照 + 多任务 + 配对检验 |
| 中 | ISBI / MIDL / SPIE | 50–60% | 2–3 月 | 换指标 + 充分消融 |
| **旁路** | **方法审计短文** | **60–70%** | **3–4 周** | **材料已在手，先做这个** |

旁路：复现查表冗余 → 量化各向异性失配 → 补零代码对照。**即使所有实验为负，论文依然成立。**

## 止损（开工前确认）

- 核心增益 CI 跨 0 → 放弃方法路线，写审计短文
- 零代码对照 ≈ SPS → 结论改为"已有参数即等效"，主结论转向
- 与竞品差距 > 3× 增益 → 放弃精度主张，转效率或标注成本

**必做第一组实验**：`max_cond_frames_in_attn ∈ {2,3,4}`，只改 config。它同时验证归因、决定档位、并为旁路论文提供核心证据 —— 投入产出比最高。

## 未核实

arXiv 检索实测 4 查 3 失败（限速），覆盖度约 60–70%。开工前必须补检：各向异性位置编码、跨平面记忆、提示效率。**这些可能推翻上述结论。** 另：动机须写"降低标注成本"而非"提高精度"，否则被 nnU-Net 一句驳回。

# 一、命题拆解

# 1.1 原始命题

> 把 SAM2 记忆库中间的 4 个空闲槽位从"时间刻度"改造成"空间刻度"，从而提高 CT 3D 分割效果。

# 1.2 四坐标还原

| 坐标 | 内容 | 状态 |
|---|---|---|
| 问题 | SAM2 的帧序先验建立在视频时间假设上，迁移到 CT 后语义失效 | 命题模糊：是"语义错配"还是"精度不足"？两者对应完全不同的问题 |
| 干预 | 记忆库的时间位置编码（`maskmem_tpos_enc`） | 相对清晰 |
| 指标 | Dice / IoU / HD | **核心缺陷**：指标与机理不匹配 |
| 竞品 | SAM2 默认 + 2603.23116 的 SPS/IS | **严重低估**：至少还有 4 篇强相关工作未纳入 |

# 1.3 命题的形式化缺陷

原命题有一处结构误判，会直接导致方案设计错误：

> "4 个空闲槽位……用来装更多东西"

**在 SAM2 的实现里，槽位不是容量，是标签。**

```python
self.maskmem_tpos_enc = torch.nn.Parameter(torch.zeros(num_maskmem, 1, 1, self.mem_dim))
maskmem_enc = maskmem_enc + self.maskmem_tpos_enc[num_maskmem - t_pos - 1]
out = output_dict["non_cond_frame_outputs"].get(prev_frame_idx, None)
if out is None:
    continue          # 拿不到特征 → 该槽位在 key 序列里根本不存在
```

`maskmem_tpos_enc` 是 7×64 的查表，每行是一个位置身份。**没有特征时，标签贴不出去，该位置不占 token、不占算力、不参与 softmax。**

因此"腾出 4 个槽装更多历史"在架构上不成立；正确命题应是"还有哪些特征值得注入，该给它们什么标签"。

# 二、源码层面的关键事实

# 2.1 记忆库是两套独立存储

```python
output_dict["cond_frame_outputs"]      # 提示帧
output_dict["non_cond_frame_outputs"]  # 非提示帧
```

# 2.2 提示帧：永久驻留、全体共用同一时间槽

```python
# all cond frames have t_pos=0
t_pos_and_prevs = [(0, out) for out in selected_cond_outputs.values()]
```

- **不淘汰**：dict 按帧号索引，无 FIFO 挤出逻辑；
- **默认全用**：`max_cond_frames_in_attn = -1`；
- **全部 `t_pos = 0`** → 统一落到 slot index `7-0-1 = 6`。

所以不是"加零向量"，而是"**第 6 号槽位那一行参数，所有提示帧共用**"。这行是学出来的、非零，但对每一帧提示都一样 —— 模型没有手段区分提示帧的远近。

# 2.3 非提示帧：6 个槽位，按距离分槽

| 帧 | 距当前 | t_pos | tpos 表槽位 |
|---|---|---|---|
| 所有提示帧 | 不定 | 0 | **6（共用）** |
| 最近的非提示帧 | t−1 | 6 | 0 |
| | t−2 | 5 | 1 |
| | t−3 | 4 | 2 |
| | t−4 | 3 | 3 |
| | t−5 | 2 | 4 |
| 最旧的非提示帧 | t−6 | 1 | 5 |

两个附加机制：被 `max_cond_frames_in_attn` 排除的提示帧若落在最近 6 帧内，会**降级**为非提示帧重新纳入；`memory_temporal_stride_for_eval` 支持稀疏抽样。

# 2.4 一个关键的不对称：object pointer 有距离编码

```python
obj_pos = get_1d_sine_pe(obj_pos / t_diff_max, dim=tpos_dim)
# use_signed_tpos_enc_to_obj_ptrs: true → 用带符号的真实帧距离
```

| 记忆类型 | 提示帧有距离信息吗 | 机制 |
|---|---|---|
| 空间记忆特征 | ❌ 没有 | 所有提示帧共用槽位 6 |
| object pointer | ✅ **有** | 真实帧距离 → 正弦编码，且带符号 |

**含义**：SAM2 并非完全不知道提示帧远近 —— object pointer 通路知道，只是空间记忆通路不知道。两条通路最后拼在同一个 cross-attention 的 key 序列里。

这给了一个比"新增机制"成本低得多的改造方向：**把 object pointer 已在用的 `get_1d_sine_pe` 复制到空间记忆特征上**，同函数、同距离、同归一化，只是当前没加到 `maskmem_enc` 上。

# 2.5 对 2603.23116 的两点重新解读

**SPS ≈ 打开 SAM2 自带的开关。** `select_closest_cond_frames()` 的文档字符串：*"Select up to `max_cond_frame_num` conditioning frames that are **temporally closest** to the current frame"*。

| | 判据 | 参数 |
|---|---|---|
| 内置 `max_cond_frames_in_attn` | 取**最近 N 个**（数量） | N=2,3,… |
| SPS | 取**距离 < 0.3 的**（阈值） | 阈值 0.3 |

**SPS 是把一个内建的数量限制换成了距离阈值。** 论文未提该参数存在，因此一个正确的 baseline 应该是"设成 2 或 3"，而非"不设"。

**IS 改哪一行未说清。** tpos 表有 7 行，"first/last"有两种读法：A 用 0 和 6（行 6 是提示帧专用槽，会污染语义）；B 用 0 和 5（两个都是非提示槽，语义干净）。**B 更可能是本意，但 A 字面也成立，复现时必须确认。**

# 三个结构性劣势

**劣势 1：基线本身不临床可用。** 0.804 建立在真值 mask 提示之上，医生给不出完美 mask。任何在此之上的 2–3 点改进，在真实提示下可能不成立。

**劣势 2：最大增益来自预处理。** 同一论文中，无预处理 0.594 → 窗宽窗位处理后 0.804（**+21 点**），而全部记忆机制改造合计 +3.7 点。**记忆机制是这条线上最小的杠杆。**

**劣势 3：与 nnU-Net 无法正面竞争。** 因此任何以"Dice 更高"为卖点的方案都会被一句话驳回。

**结论：唯一站得住的立论是"同精度下标注成本更低"。** 这决定了指标必须换。

# 五、框架重定位

# 5.1 为什么必须重定位

关 2（效应量）的失败不是方法缺陷，是**指标与机理不匹配**。记忆机制的本质是"用少量真实信息扩散到全体"，这个作用在**均值 Dice** 上被稀释，在**效率曲线**上则被放大。

# 5.2 路径 A：换指标

```
横轴：提示预算（1 / 2 / 3 / 5 / 9 个提示，或提示覆盖层数占比）
纵轴：Dice
报告：AUC、达到目标精度所需最小提示数、相对节省比例
```

若基线需 5 个提示达到 0.85 而新方法只需 3 个，这是 **40% 的相对改进** —— 在均值 Dice 上表现为 +1 点（不可测），在曲线上是明确的、可解释的、临床有意义的差距。

**额外收益**：绕开与 nnU-Net 的正面竞争（任务不同），且直接对应临床价值。SLM-SAM 2 在 TMI 上正是主打"Dice + 修正时间降低 60%"—— 这是该领域审稿人已接受的叙事。

# 5.3 路径 B：换论点

> **视频基础模型的记忆位置编码本质是"帧序号先验"。当数据采样从等间隔时序变为各向异性的空间采样时，该先验退化为一张中间段无区分度的查表；而这种退化正是视频记忆超参无法迁移到体数据的直接原因。**

支撑证据（**全部已在手**）：

1. 查表结构：提示帧共用 slot 6，非提示帧 slot 0–5 中仅两端有区分度；
2. 两条通路不一致：空间记忆用离散查表，object pointer 用连续正弦距离编码；
3. 各向异性量化：CT 的 z 间距常为 xy 的 3–5 倍，故"t−6"对应的物理距离跨病例变化达一个数量级（推断，需实测）；
4. 既有工作的间接印证：2603.23116 发现中间编码冗余并据此删帧（+1.8）、SLM-SAM2 需重构记忆库（+0.14）。

**为什么这个叙事更强**：不需要新方法就有结论；有一个可证伪的预测（若机理成立，"保留 6 帧但给 6 个互不相同标签"应 ≥ "删到 2 帧"）；不与任何竞品冲突。

```python
# 修改点唯一：sam2/modeling/sam2_base.py::_prepare_memory_conditioned_features
# 原：
maskmem_enc = maskmem_enc + self.maskmem_tpos_enc[self.num_maskmem - t_pos - 1]

# 建议（零初始化残差，保证初始状态 == 原始 SAM2）：
slot_pe = self.maskmem_tpos_enc[self.num_maskmem - t_pos - 1]   # 保留原表
d_mm    = abs(z_slice - z_current) * spacing_z                   # 物理距离
d_norm  = d_mm / self.d_ref                                      # d_ref = 中位层厚
cont_pe = self.pe_mlp(get_1d_sine_pe(d_norm, dim=self.mem_dim))  # 复用已有函数
maskmem_enc = maskmem_enc + slot_pe + cont_pe                    # pe_mlp 末层零初始化
```

三个设计要点：`pe_mlp` 末层零初始化使初始输出严格等于原始 SAM2，任何增益可归因；`get_1d_sine_pe` 是同一份源码里已在用的函数，反驳"分布外风险"；不训练也能跑，训练可更强，同时覆盖两派读者。

# 八、周期与算力

| 阶段 | 周次 | 工作 | 决策点 | 决策规则 |
|---|---|---|---|---|
| P0 | 1 | 补做完整新颖性检索 | 是否继续 | 发现直接对标 → 转向旁路 |
| P1 | 2 | G0 + G1 + G2（只改 config） | **归因是否成立** | ≈SPS → 旁路成立，主路径降级 |
| P2 | 3 | G3 + G4 + G6 | **核心发现是否成立** | G6 ≥ G4 → "命名失效"成立 |
| P3 | 4–6 | G5 + G7 + G8 | 效应量是否够 | 见止损 S1 |

**并行建议**：P1/P2 只用 CPU 级改动，可在等 GPU 排期时先做。若这些结论已足以支撑旁路论文，可提前启动写作，形成"保底一篇 + 冲刺一篇"的结构。

**算力**：500 例子集单次推理约 50 min（RTX 3090 级）；主实验合计约 **25–35 GPU·h**。瓶颈在设计与分析，不在算力 —— 这既是优点（门槛低）也是缺点（竞争者也能快速跟进）。

# 应当一并纳入诊断的三件事

**第一，"值不值得做"需单独论证。** CT 骨骼分割本身已有成熟解法。SAM2 路线的真实价值是**交互式标注加速**，不是替代全监督。若动机写"提高 3D CT 分割精度"，必然被 nnU-Net 挡回；若写"降低医生标注成本"，才站得住。这决定整篇论文的定位，不是措辞问题。

**第二，真实约束比方法论更重要。** 三项未知会显著改变档位建议：可用算力（单卡 24GB 时 G9 需缩规模）、是否有临床合作（没有则"标注成本节省"只能用模拟交互，说服力打折）、时间窗口（3 个月内必须出成果则应直接做旁路）。

**第三，这条线已呈"负结果密集"特征，本身是信号。** 已确认的负结果：置信度 gating 掉点、单轴双向传播掉点、中间时间编码冗余、内容路由不如位置路由（SAM+D Table 10）。**四条独立负结果指向同一件事：在体数据上，"基于内容统计/更多方向"的记忆策略普遍无效，只有"基于位置邻近"的才有效。**

这个收敛比任何一个 +2 点的改进都更有信息量。**如果我是审稿人，我更愿意看到一篇系统解释"为什么内容驱动的记忆在体数据上失效"的论文，而不是第五篇"我调了记忆库"的论文。**
